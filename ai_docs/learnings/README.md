# learnings — Review Learnings (self-improvement loop)

Learnings captured from the review stage, meant to be fed back into the ADW so it
improves its own processes over time — the self-learning loop.

- Failures are training data: a defect that slips a gate becomes a lesson here.
- Learnings tighten specs, prompts, and gates so the next run is cheaper and safer.
- The system improves the system.
